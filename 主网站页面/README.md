# Apple 官网克隆项目

这是一个高度还原的苹果国际版官网克隆项目，采用现代化的设计理念和最佳实践构建。

## 🎨 设计特色

### 视觉设计
- **极简主义风格**：遵循苹果的设计语言，注重留白和层次感
- **现代化配色**：使用苹果官方色彩体系，确保品牌一致性
- **优雅的排版**：采用 SF Pro Display 字体系列，提供最佳阅读体验
- **精致的图标**：SVG 矢量图标，确保在任何分辨率下都清晰锐利

### 用户体验
- **流畅的动画**：精心设计的过渡效果和微交互
- **响应式设计**：完美适配桌面、平板和移动设备
- **直观的导航**：清晰的信息架构和用户路径
- **快速加载**：优化的代码结构，确保最佳性能

## 🚀 功能特性

### 核心功能
- ✅ **响应式导航栏**：固定顶部导航，支持滚动隐藏/显示
- ✅ **英雄区域**：大屏幕展示主打产品，配有 3D 效果
- ✅ **产品网格**：灵活的产品展示布局
- ✅ **交互动画**：鼠标悬停效果和滚动动画
- ✅ **移动端优化**：完整的移动端适配

### 交互效果
- 🎭 **视差滚动**：英雄区域的视差效果
- 🎯 **3D 旋转**：iPhone 模型的鼠标跟随效果
- 💫 **涟漪动画**：按钮点击的涟漪反馈
- 🌊 **平滑滚动**：页面内锚点的平滑滚动
- 👀 **入场动画**：元素进入视窗时的淡入效果

## 🎯 设计原则

### 用户体验设计
1. **简洁性**：去除不必要的元素，专注核心内容
2. **一致性**：统一的设计语言和交互模式
3. **可用性**：直观的操作流程和清晰的反馈
4. **可访问性**：支持键盘导航和屏幕阅读器

### 视觉层次
1. **主要内容**：使用大字号和高对比度
2. **次要信息**：适中的字号和中等对比度
3. **辅助元素**：小字号和低对比度

### 响应式策略
- **移动优先**：从小屏幕开始设计，逐步增强
- **断点设计**：480px、768px、1024px 三个主要断点
- **弹性布局**：使用相对单位，确保内容自适应

## 🚀 快速开始

1. **克隆项目**
   ```bash
   # 直接打开 index.html 文件即可
   ```

2. **本地预览**
   - 双击 `index.html` 文件
   - 或使用本地服务器（推荐）

3. **开发环境**
   ```bash
   # 使用 Python 启动本地服务器
   python -m http.server 8000
   
   # 或使用 Node.js
   npx serve .
   ```

## 📱 响应式断点

| 设备类型 | 屏幕宽度 | 布局特点 |
|---------|---------|----------|
| 手机 | < 480px | 单列布局，简化导航 |
| 平板 | 480px - 768px | 两列布局，保留主要功能 |
| 桌面 | 768px - 1024px | 多列布局，完整功能 |
| 大屏 | > 1024px | 最大宽度限制，居中显示 |

## 🔧 自定义配置

### 修改主题色
在 `styles.css` 文件顶部修改 CSS 变量：
```css
:root {
  --primary-color: #your-color;
  --secondary-color: #your-color;
}
```

### 添加新产品
在 `index.html` 的产品网格部分添加新的产品卡片：
```html
<div class="product-card">
    <div class="card-content">
        <h3>产品名称</h3>
        <p>产品描述</p>
        <div class="card-cta">
            <a href="#" class="btn-link">了解更多</a>
            <a href="#" class="btn-link">购买</a>
        </div>
    </div>
    <div class="card-image your-product"></div>
</div>
```
